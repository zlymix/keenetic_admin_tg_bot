# Keenetic Router Admin Telegram Bot (Go)

Telegram-бот на Go для управления роутером Keenetic (KeeneticOS / NDMS) через RCI API.

## Возможности

1. **Список устройств сети:**
   - Отображение подключенных (online) и всех зарегистрированных устройств.
   - Приоритет отображения: **название устройства** (заданное пользователем в Keenetic) → **сетевое имя (hostname)** → **MAC-адрес**.
   - Отображение IP-адреса, времени в сети (uptime), объема переданного трафика (Rx/Tx).
2. **Текстовый список устройств по времени активности (`/devices` или `/online`):**
   - Вывод списка устройств простым текстом с разделением на два блока:
     - 🟢 **Онлайн:** отсортированы по времени нахождения в сети по возрастанию (сначала те, что подключились недавно, затем те, что в сети дольше).
     - 🔴 **Оффлайн:** отсортированы по времени отключения (вверху списка те, что отключились недавно, внизу — те, что отключились давно или неизвестно).
   - Сроки и переходы состояний фиксируются ботом в базе `data/history.json`.
   - Кнопка «⏱ По времени» также доступна в меню устройств.
3. **Избранные устройства:**
   - Добавление и удаление устройств в избранное в один клик.
   - Избранные устройства отображаются в самом начале списка с меткой ⭐.
   - Избранные устройства видны на главной вкладке, даже если они офлайн (не требуется переходить во вкладку "Все").
   - База данных избранного сохраняется в JSON-файл в директории `data/`.
4. **Управление доступом в Интернет (Политика "No Internet Access"):**
   - Возможность в 1 клик выключить или включить доступ к интернету для любого устройства (правило `deny` / `permit`).
5. **Ограничение скорости интернета:**
   - Предустановленные лимиты скорости (1, 3, 5, 10, 20, 50 Мбит/с) или снятие ограничения (безлимит).
6. **Wake on LAN (WOL):**
   - Отправка «магического пакета» для удаленного пробуждения любого устройства по MAC-адресу.
7. **Состояние интернет-подключений:**
   - Отображение статуса всех внешних провайдеров и туннелей (PPPoE, L2TP, Wireguard, OpenVPN, ISP и т.д.): подключен/отключен, внешний IP, аптайм, ошибки.
8. **Перезагрузка роутера:**
   - Кнопка перезапуска роутера с диалогом подтверждения.
9. **Компактные уведомления о входе/выходе устройств:**
   - Фоновый монитор отправляет ультра-компактные сообщения: `🟢 <b>Название</b>` (при входе) и `🔴 <b>Название</b>` (при выходе), или MAC-адрес при отсутствии названия. Без лишнего текста, IP и времени.
10. **Безопасность и авторизация:**
   - Challenge-Response (MD5 + SHA-256) авторизация по схеме Keenetic.
   - Токен (cookie сессии) сохраняется и переиспользуется; при истечении токена происходит прозрачная повторная авторизация.
   - Middleware авторизации по белому списку Telegram ID пользователей.

## Библиотеки

- HTTP-клиент: [`github.com/imroc/req/v3`](https://github.com/imroc/req/v3)
- Telegram Bot API: [`gopkg.in/telebot.v4`](https://github.com/tucnak/telebot)
- YAML парсер: [`gopkg.in/yaml.v3`](https://github.com/gopkg.in/yaml.v3)

## Структура проекта

```
keenetic_admin/
├── cmd/
│   └── bot/
│       └── main.go              # Точка входа приложения
├── internal/
│   ├── config/
│   │   └── config.go            # Загрузка и структура config.yaml
│   ├── storage/
│   │   ├── favorites.go         # Хранилище избранных устройств (JSON)
│   │   └── favorites_test.go
│   ├── keenetic/
│   │   ├── client.go            # HTTP-клиент к RCI API Keenetic
│   │   ├── models.go            # Модели данных (устройства, интерфейсы)
│   │   └── client_test.go       # Интеграционные тесты клиента
│   └── bot/
│       ├── handlers.go          # Обработчики команд, меню и кнопок
│       ├── handlers_test.go     # Тесты обработчиков бота
│       ├── middleware.go        # Проверка прав доступа пользователей
│       └── monitor.go           # Фоновый монитор входа/выхода устройств
├── data/                        # Том (volume) для постоянного хранения
│   ├── config.yaml              # Конфигурационный файл
│   └── favorites.json           # База избранных устройств
├── Dockerfile                   # Локальная многоэтапная сборка
├── docker-compose.yml           # Запуск в Docker
├── config.yaml.example          # Пример конфигурационного файла
├── go.mod
└── go.sum
```

## Настройка

Конфигурационный файл находится в папке `data/config.yaml`:

```yaml
telegram:
  # Токен от @BotFather
  bot_token: "123456789:ABCDefGhIJKlmNoPQRsTUVwxyZ"
  
  # Список Telegram User ID пользователей, которым разрешен доступ
  allowed_users:
    - 123456789

  # ID чата для уведомлений о подключении/отключении устройств
  notification_chat_id: 123456789

router:
  url: "http://192.168.1.1"
  login: "admin"
  password: "tmpPASS123"
  poll_interval_seconds: 30

storage:
  favorites_file: "data/favorites.json"
```

## Запуск

### Запуск через Docker Compose (Рекомендуется):

```bash
# Сборка и запуск в фоне
docker compose up -d --build

# Просмотр логов
docker compose logs -f

# Остановка
docker compose down
```

### Локальный запуск без Docker:

```bash
# Тесты
go test -v ./...

# Запуск
go run ./cmd/bot -config data/config.yaml
```
